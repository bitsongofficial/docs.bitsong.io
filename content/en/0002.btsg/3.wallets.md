BitSong recommends using the Keplr wallet for BitSong mainnet BTSG tokens management from desktop. You can access the [UI Dashboard](https://wallet.bitsong.io) via Keplr and perform transfers or governance actions.

## Keplr

Keplr is a browser extension and mobile wallet designed to support the Cosmos Internet of Blockchains. You can use Keplr to store, send, or receive mainnet-BTSG tokens. You can also stake your BTSG tokens directly to a Validator on the BitSong mainnet from your Keplr wallet.

::tabs
  :::tabs-item{label="Extension" icon="i-lucide-puzzle"}
  ::::steps{level="4"}

  #### Install the extension

  You will need the Chrome browser (or Brave). Download [Keplr](https://chrome.google.com/webstore/detail/keplr/dmkamcknogkgcdfhhbddcghachkejeap) from the Chrome Web Store.

  #### Add BitSong to Keplr

  Add the BitSong mainnet to your Keplr wallet [following these instructions](/en/useful-guides/wallet/how-to-create-a-bitsong-wallet).

## Cosmostation

100% non-custodial wallet that supports multiple sovereign networks and inter-chain bridges.

::tabs
  :::tabs-item{label="Extension" icon="i-lucide-puzzle"}
  [Cosmostation Wallet Extension](https://chrome.google.com/webstore/detail/cosmostation/fpkhgmpbidmiogeglndfbkegfdlnajnf?utm_source=chrome-ntp-icon) is a 100% non-custodial chrome extension wallet that supports multiple sovereign networks and inter-chain bridges.

  ::::steps{level="4"}

  #### Install the extension

  Download [Cosmostation Wallet Extension](https://chrome.google.com/webstore/detail/cosmostation/fpkhgmpbidmiogeglndfbkegfdlnajnf?utm_source=chrome-ntp-icon) from the Chrome Web Store.

  #### Create or import a wallet

  Open the extension, create a new wallet or import an existing one using your mnemonic seed phrase.

  #### Select BitSong

  Search for BitSong in the networks list and add it to your wallet.

## Leap Wallet

Leap is a non-custodial super wallet for web3. It is already live on Cosmos & Terra 2.0, while it is expected to be deployed soon on Avalanche too. BitSong is integrated with full support.

::tabs
  :::tabs-item{label="Extension" icon="i-lucide-puzzle"}
  ::::steps{level="4"}

  #### Install the extension

  Download [Leap Wallet Web extension for Cosmos](https://chrome.google.com/webstore/detail/leap-cosmos-wallet/fcfcfllfndlomdhbehjjcoimbgofdncg/?utm_source=website&utm_medium=permanent-website&utm_campaign=permanent) from the Chrome Web Store.

  #### Create or import a wallet

  Open the extension and create a new wallet or import one via the available options.

  #### Start managing your BTSGs

  You're all set — start managing your BTSGs on Leap Wallet.

  ::::
  :::

  :::tabs-item{label="Mobile" icon="i-lucide-smartphone"}
  ::::card-group
    :::::card{title="Android" icon="i-lucide-smartphone" to="https://www.leapwallet.io/cosmos"}
    Download from Google Play
    :::::
    :::::card{title="iOS" icon="i-lucide-tablet-smartphone" to="https://www.leapwallet.io/cosmos"}
    Download from App Store
    :::::
  ::::

  ::::steps{level="4"}

  ### Create or import your wallet

  Once installed, open the app and create a new wallet or import an existing one.

  ### Select BitSong

  Tap the blockchain icon (upper right), which is usually set to Cosmos Blockchain by default, and look for BitSong in the chains list. Select it and you're all set, ready to copy and distribute your BitSong wallet address.
